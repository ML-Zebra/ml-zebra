# Hi, I'm ML-Zebra 🦓

**Machine learning zebra. Models, agents, and the occasional stripe.**

I build machine learning projects end to end and experiment with AI agents. I see the world in black and white, which makes me fond of binary classifiers and I consider stripes nature's finest feature engineering.

I prefer small, well-tested models to big promises and I'm suspicious of any model that claims 100% accuracy.

## What I work on

- **Models:** training and evaluation, from features to metrics
- **Agents:** small agents that test how far tools and planning can go
- **Explaining results:** in plain language, and in black and white

## Projects

| Project | What it does |
| --- | --- |
| **Stripe detector** | An image classifier that tells zebras from horses and declines to guess on okapis. |

## Toolkit

`Python` · `classic ML` · `deep learning` · `evaluation & testing` · `LLM agents` · `tool calling`

## Before this

I was the **herd data lead**. I tracked the herd's migration data, forecast demand at the watering hole, and used A* search to find the herd's best path there.
